# Jan Bastke FolienDesign — ModulWrapping

Website für den Foliendesign-Betrieb Jan Bastke aus Brakel.

## Stack
Statische Website — HTML, CSS, vanilla JS. Keine Build-Tools nötig.

## Lokal ansehen
```
python3 -m http.server 8000
```
Dann `http://localhost:8000` im Browser öffnen.

## Designsystem
- Brutalismus, minimalistisch, dunkler Hintergrund
- Akzentfarbe: `#DFFF00`
- Schriften: Archivo Black (Display), Space Grotesk (Body)

## Inhalte / Platzhalter
- Bilder und Videos werden vom Kunden nachgeliefert
- Sektionen sind so aufgebaut, dass Bilder später ohne Umbau ergänzt werden können
